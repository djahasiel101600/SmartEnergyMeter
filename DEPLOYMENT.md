# Deployment Guide for Render.com

This guide explains how to deploy the Smart Energy Meter system to Render.com.

## Prerequisites

1. Create a Render.com account at https://render.com
2. Install Render CLI (optional): `npm install -g render`
3. Have your code in a Git repository (GitHub, GitLab, or Bitbucket)

## One-Click Deployment

The easiest way to deploy is using the `render.yaml` file:

### Step 1: Connect Repository

1. Log in to Render Dashboard
2. Click "New +" → "Blueprint"
3. Connect your Git repository
4. Render will automatically detect `render.yaml`

### Step 2: Configure Environment Variables

The following environment variables need to be configured:

**Backend Service:**

- `SECRET_KEY` - Auto-generated by Render
- `DATABASE_URL` - Auto-connected from PostgreSQL
- `REDIS_URL` - Auto-connected from Redis
- `CORS_ALLOWED_ORIGINS` - Add your frontend URL (e.g., `https://your-frontend.onrender.com`)

### Step 3: Deploy

1. Click "Apply" to create all services
2. Wait for build and deployment (5-10 minutes)
3. Services will be available at:
   - Backend: `https://smart-energy-backend.onrender.com`
   - Database: Internal connection
   - Redis: Internal connection

## Manual Deployment

If you prefer to deploy manually:

### 1. Deploy PostgreSQL Database

```bash
# In Render Dashboard:
New + → PostgreSQL
Name: smart-energy-db
Database: smart_energy
User: smart_energy_user
Region: Singapore (or closest to you)
Plan: Free
```

### 2. Deploy Redis

```bash
# In Render Dashboard:
New + → Redis
Name: smart-energy-redis
Region: Singapore
Plan: Free
```

### 3. Deploy Backend

```bash
# In Render Dashboard:
New + → Web Service
Connect your repository
Name: smart-energy-backend
Region: Singapore
Branch: main (or master)
Root Directory: (leave empty)
Environment: Python 3
Build Command: ./build.sh
Start Command: cd backend && daphne -b 0.0.0.0 -p 10000 backend.asgi:application
Plan: Free

# Environment Variables:
SECRET_KEY=<generate-random-key>
DEBUG=False
ALLOWED_HOSTS=smart-energy-backend.onrender.com
DATABASE_URL=<from-postgresql-internal-url>
REDIS_URL=<from-redis-internal-url>
CORS_ALLOWED_ORIGINS=https://your-frontend-url.com
TIME_ZONE=Asia/Manila
PYTHON_VERSION=3.11
```

### 4. Deploy Frontend (Optional)

If you want to deploy the React frontend on Render as well:

```bash
# In Render Dashboard:
New + → Static Site
Connect your repository
Name: smart-energy-frontend
Root Directory: frontend
Build Command: npm install && npm run build
Publish Directory: dist

# Environment Variables:
VITE_API_URL=https://smart-energy-backend.onrender.com/api
VITE_WS_URL=wss://smart-energy-backend.onrender.com/ws/energy/
```

## Post-Deployment

### 1. Create Superuser

```bash
# Via Render Shell:
cd backend
python manage.py createsuperuser
```

### 2. Create Device Token

1. Access admin: `https://smart-energy-backend.onrender.com/admin/`
2. Log in with superuser credentials
3. Add Device:
   - Name: "Living Room Meter"
   - Token: Generate a random token (e.g., UUID)
   - LCD enabled: Yes
   - Save

4. Copy the device token for ESP8266 configuration

### 3. Configure ESP8266

Copy `firmware/include/config.h.example` to `firmware/include/config.h` and update:

```cpp
#define WS_SERVER "smart-energy-backend.onrender.com"
#define WS_PORT 443
#define DEVICE_TOKEN "your-device-token-from-admin"
```

Upload firmware using PlatformIO:

```bash
cd firmware
pio run --target upload
```

Note: Use port 443 for WSS (WebSocket Secure) on Render.

### 4. Update CORS Settings

Add your frontend URL to `CORS_ALLOWED_ORIGINS` in Render environment variables:

```
CORS_ALLOWED_ORIGINS=https://your-frontend.onrender.com,http://localhost:5173
```

## Database Migrations

Migrations run automatically during deployment via `build.sh`.

To run manually:

```bash
# Via Render Shell
cd backend
python manage.py migrate
```

### Free Tier Limitations:

- Backend: Sleeps after 15 minutes of inactivity
- PostgreSQL: 1GB storage, 97 hours/month
- Redis: 25MB storage

### To Upgrade:

1. Go to Service Settings
2. Change Plan (Starter: $7/month, Standard: $25/month)

## Troubleshooting

### WebSocket Connection Issues

1. Ensure you're using WSS (not WS) for production
2. Check ALLOWED_HOSTS includes your domain
3. Verify REDIS_URL is correctly set

### Database Connection Errors

1. Check DATABASE_URL environment variable
2. Verify PostgreSQL service is running
3. Check connection string format

### Static Files Not Loading

1. Run `python manage.py collectstatic`
2. Check STATIC_ROOT and STATIC_URL settings
3. Verify build.sh runs successfully

### Backend Sleeping (Free Tier)

- Services sleep after 15 min inactivity
- First request after sleep takes 30-60 seconds
- Upgrade to paid plan to prevent sleeping

## Security Best Practices

1. **SECRET_KEY**: Use Render's auto-generated value
2. **DEBUG**: Always set to `False` in production
3. **ALLOWED_HOSTS**: Restrict to your domain
4. **DATABASE_URL**: Never commit to Git
5. **HTTPS**: Always use WSS for WebSocket in production

## Backup

### Database Backup

```bash
# Manual backup via Render Shell:
pg_dump $DATABASE_URL > backup.sql

# Restore:
psql $DATABASE_URL < backup.sql
```

### Automated Backups

Render automatically backs up PostgreSQL databases daily (retained for 7 days on free tier).
